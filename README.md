# Annotation comparison

Порівняння ручної розмітки фото з еталонною. Скрипт читає два JSON-файли з
метаданими (самі зображення не потрібні) і рахує, наскільки точно силуети
об'єктів збігаються з еталоном.

## Що всередині

- `main.py` — точка входу: завантаження JSON, співставлення об'єктів, звіт у консоль.
- `geometry.py` — геометрія: площа за формулою шнурування, перетин/об'єднання
  полігонів (через `shapely`), перевірка валідності.
- `annotated/` — приклад ручної розмітки (`road.jpg.json`).
- `ground_truth/` — приклад еталона (`road.jpg.json`).
- `spec.md`, `script_spec.md`, `implementation_plan.md` — постановка задачі й деталі реалізації.

## Вимоги

- Python 3.10+ (використовується сучасний синтаксис типів)
- `shapely>=2.0,<3` (див. `requirements.txt`)

## Встановлення

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py <annotated.json> <ground_truth.json>
```

Перший аргумент — ручна розмітка, другий — еталон. Приклад:

```powershell
python main.py annotated\road.jpg.json ground_truth\road.jpg.json
```

Результат виводиться лише в консоль; файли не створюються і не змінюються.

## Формат вхідних файлів

JSON — масив із двох елементів:

1. Метадані: `width`, `height`, `objects` (кожен об'єкт має `nm`, `type`,
   `shape` — `bBox` або `poly`), а також `attributes.weather`.
2. Геометрія: `objects` із тим самим `nm`, координатами `x1 y1 x2 y2` для
   прямокутників і `path` для багатокутників.

## Що показує звіт

- `Image size` / `Weather` — збіг із еталоном або попередження.
- Таблиця пар об'єктів: `I` (площа перетину, px²), `U` (площа об'єднання, px²),
  `Score = I / U`. Об'єкти без пари позначаються `UNMATCHED` і мають score 0.
- `TOTAL` — загальний score: `sum(I) / sum(U)`.
- `NOTES` — зауваження щодо якості даних (відсутня геометрія, невалідні або
  вироджені полігони, координати поза межами зображення тощо).

## Коди виходу

- `0` — порівняння виконано.
- `2` — помилка вхідних даних (файл не знайдено, некоректний JSON або структура);
  повідомлення виводиться в `stderr`.
