Є задача розмітки фото для датасетів - визначення границь об'єктів (авто, дорожні знаки тощо).
Є ідеально розмічений еталон (у папці groun_trith) та вручну розмічений (у папці annotated).
До кожного фото додається файл (формат json) у відповідній директорії із метаданими розмічених фотографій.

Ціллю є порівняти наскільки точно вручну розмічене фото відповідає еталонному (самі фото порівнювати не треба, лише файли із метаданими).
Метадані утворюють силуети об'єктів у вигляді ламаних фігур (за координатами). Отримані силуети еталона та вручну розміченого можуть бути різного розміру та мати різне розташування.
Для порівняння вводиться показник score.

score = I / U , де I - площа фігури перетину фігури еталона та фігури ручного (A & B), U - загальна складена площа фігури фігури еталона та фігури ручного (A | B, важливо - це не сума окремо взятих площ).

Кількість силуетів в еталоні та в ручному може відрізнятись - зайві (яким немає пари) вважати що мають score рівним 0.
Для випадків коли одну фігуру одного класу (наприклад еталона) перетинає декілька фігур іншого класу (наприклад ручного) потрібно порахувати score для усіх пар фігур, що перетинаються, і обрати найбільше значення score (тоді цю пару вважаємо відповідником для фігури еталона та фігури ручного).

Оскільки фігури є ламаними, то для обчислення площь за координатами можна використати алгоритм шнурування Гаусса.

Для обчислення загальної відповідності вручну розміченого файла еталонному використовується score (заг.).

score (заг.) = sum(I) / sum(U) , де sum(I) - сума площ фігур перетину фігури еталона та фігури ручного, sum(U) - сума загальних складениї площ фігур фігури еталона та фігури ручного.


Поля файлу json для scope задачі:
1. width, height - ширина і висота фото, якщо відмінні - має бути попередження, якщо рівні - підтвердження
2. weather - визначена погода за фото, якщо відмінні - має бути попередження, якщо рівні - підтвердження
3. верхній objects - список розмічених об'єктів із загальною інформацією, де nm - ідентифікатор об'єкта, shape - тип фігури (прямокутник (bBox) або ламаний багатокутник (poly))
4. нижній objects - список розмічених об'єктів із детальнішою інформацією, де nm - ідентифікатор об'єкта, x1 y1 x2 y2 - координати вершин, path - координати проміжних вершин для ламаних багатокутників
